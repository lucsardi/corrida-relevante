Coloque aqui os seguintes arquivos de imagem:

- bg_header.png   -> imagem de fundo do header/hero (telas grandes, >=992px)
- bg_mobile.gif   -> imagem de fundo do header/hero (telas pequenas, <992px)
- logo_r.png      -> logo exibida na navbar
- title_bg.png    -> título estilizado do evento (visível só em telas grandes)
- subtitle_bg.png -> subtítulo estilizado do evento (visível só em telas grandes)

Caminhos usados no código:
- index.html    -> assets/images/logo_r.png
- index.html    -> assets/images/title_bg.png
- index.html    -> assets/images/subtitle_bg.png
- css/style.css -> ../assets/images/bg_header.png (desktop)
- css/style.css -> ../assets/images/bg_mobile.gif (mobile, <992px)
